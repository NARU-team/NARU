# 나루(NARU)

> 차에서 머무는 모든 순간을 나만의 쉼으로.

장소와 차량 상태를 이해하고, 차박부터 짧은 낮잠까지 온도·조명·소리·기상 환경을 맞춤 설정하는 **차량용 AI 휴식 에이전트**입니다.

## 모드

- **차박 모드**: 도착 점검 → 잠들기 전 → 밤 → 기상
- **잠깐 쉬기 모드**: 휴식 시간 선택 → 휴식 환경 설정 → 알람 → 상태 복구

## 기술 스택

- Kotlin · Jetpack Compose
- Pleos Connect SDK (Vehicle, FusedLocation, TextToSpeech)
- 기상청 단기예보 API, 국립해양조사원 조석예보 API
- 생성형 AI (멘트 생성)
