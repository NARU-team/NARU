## 충돌과 안전 우선

- Figma 예시의 “25°C로 올렸어요”는 실제 적용 전 문구로 사용하지 않는다. READY에서는 예정 설정 변경, RESTING에서는 SDK 재조회 성공 뒤에만 적용 성공으로 표시한다.
- Figma의 “글레오 요청”은 실제 Gleo SDK가 확인되지 않아 로컬 규칙 기반 처리로 명시한다.
- v.3 휴식 중 화면에는 10분 버튼이 없지만 최종 기획서의 5/10분 연장 요구를 삭제하지 않았다. 10분은 알람 화면에서 유지한다.
- Figma에 외부 음악 앱 진입 버튼이 있으나 대상 앱/Intent/차량 정책 계약이 없어 구현하지 않았다.
- 공조나 조명 실패 시 앱 타이머·화면·자연음·알람은 계속 사용할 수 있다.

## 외부 의존성과 확인 필요

- Gleo AI: 실제 SDK와 권한 미확인, SDK_BLOCKED.
- 쉼표 서버: 계약 문서만 있으며 실제 endpoint 미연동, PARTIAL.
- 외부 음악 앱 버튼: 대상과 Intent 정책 기획자 확인 필요.
- Figma 원본 로고/아이콘: MCP 호출 한도로 에셋 다운로드·라이선스 검증 미완료.
- 충전 상태: 확인된 Pleos API는 SOC뿐이므로 에너지 예측의 충전 제외 근거 부족.
- NaviHelper: v.3 10개 쉼표 화면에서 경로 정보가 확인되지 않아 이번 UI 범위에는 추가하지 않음.
- Pleos Emulator는 v2.1.0 cold boot, APK 설치·실행, 설정 화면 렌더링까지 확인했다. 차량 제어 전체 시나리오는 UNVERIFIED.
- Room Migration 계측은 androidTest 소스와 과거 schema fixture가 없어 UNVERIFIED.
- 독립 `/api/comma/intent`와 Android client를 유지하며 서버 실패 시 LOCAL_RULE로 fallback한다. Gleo Interface는 schema/전용 Activity/action filter/callback까지 구현했고 ADB Action 수신을 확인했다. 실제 Gleo AI는 schema 심사 전이라 UNVERIFIED다.
